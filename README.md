# RBM-Plankton

Restricted Boltzmann Machine for unsupervised learning of plankton community
structure from Lake Greifen monitoring data (2019–2024).

**Dataset**: Eyring et al. (2025). *Scientific Data* 12:653 — 5 years of high-frequency
phytoplankton and zooplankton observations from Lake Greifen.
DOI: [10.1038/s41597-025-04988-9](https://doi.org/10.1038/s41597-025-04988-9)

## Quick start

```bash
# 1. Clone & install
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Place your data (see data requirements below)
#    data/raw/TimeSeries_countsuL_clean.csv

# 3. Run a single training
python code/train/train.py

# 4. Analyse results
python code/diagnostic/sweep_analysis.py
python code/analysis/hidden_coactivation.py
```

**You need the raw dataset (`data/raw/`) and trained model weights (`trained_models/`) to actually run.** The raw data is not distributed in this repo (see `.gitignore`). Trained weights are regenerated by `train.py`.

## Data requirements

Place the raw CSV at `data/raw/TimeSeries_countsuL_clean.csv` (83 taxa columns,
daily resolution, organisms/µL). This file is gitignored — users must provide it.

The pipeline automatically handles:
- Dropping all-zero and fully-NaN rows
- COUNT_SCALE=1000 (organisms/µL → organisms/mL) for numerical stability
- Binarisation (Bernoulli families) at per-taxon median threshold
- Train/val split (85/15, chronological or shuffled)

## Usage

### Training

All hyperparameters are in `code/train/config.py`:
- `SINGLE_RUN=True` trains one model (default: nb_sigmoid L=6)
- `SINGLE_RUN=False` runs a multi-(family, L, seed) sweep
- CLI overrides: `--family`, `--L`, `--single-run`, `--shuffled`

```bash
# Single run (default: nb_sigmoid L=6 seed=0)
python code/train/train.py

# Single run with overrides
python code/train/train.py --family nb --L 6 --single-run

# Multi-seed sweep (edit L_VALUES and N_SEEDS in config.py first)
python code/train/train.py --no-single-run
```

Results go to `trained_models/{family}_L{n}/seed_{k}/`.

**Model families:**

| Family | Visible | Hidden | Training | Notes |
|--------|---------|--------|----------|-------|
| `nb` | NB | Bernoulli | PCD-1 | Canonical NB baseline |
| `zinb` | ZINB | Bernoulli | PCD-1 | |
| `nb_sigmoid` | NB | Sigmoid | PCD-1 | Recommended — best NLL (LOG-021) |
| `nb_softmax` | NB | Softmax | PCD-1 | Abandoned — collapses (LOG-022) |
| `zinb_sigmoid` | ZINB | Sigmoid | PCD-1 | |
| `zinb_softmax` | ZINB | Softmax | PCD-1 | |
| `bernoulli_median` | Bernoulli (median) | Bernoulli | CD-1 | |
| `bernoulli_zero` | Bernoulli (zero) | Bernoulli | CD-1 | Near-trivial (LOG-005) |

## Status

| Stage | Status |
|-------|--------|
| Dataset EDA | Done |
| L-sweep (N=10 seeds, L∈{3,4,5,6,7}, all families) | Done |
| L selection | Done — L=6 for all families (LOG-017) |
| Hidden activation analysis | Done |
| Cross-model comparison (NB vs BB-median) | Done |
| NaN test set evaluation | In progress |

**Key results:**
- L=6 selected: cumulative ~2.5% NLL/PLL gain over L=3; no gain at L=7
- Both NB-RBM and BB-median independently recover the same two dominant
  ecological axes (summer community, winter community)
- NB uses compositional representation (~30 distinct 6-bit patterns);
  BB-median uses exclusive switching
- `bernoulli_zero` is near-trivial, confirming the median threshold decision
